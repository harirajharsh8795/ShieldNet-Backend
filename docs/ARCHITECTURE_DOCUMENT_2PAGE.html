2. Tri-Telemetry Ingestion, Graph Topology & State Standardization

ShieldNet ingests multi-modal network data into continuous vectors $S_t \in \mathbb{R}^{84}$ and dynamic communication graphs $G_t = (V, E, X_t)$:

Tier 1: NetFlow Dynamics (77 Features)

Bidirectional flow duration, packet length variance, IAT stats (mean, std, max, min), TCP flags (SYN, ACK, RST, PSH, URG), subflow bytes, and packet velocity extracted from CIC-IDS, UNSW-NB15, and CTU-13.

Tier 2: Packet Micro-Dynamics (7 Features)

IP TTL variance (`ttl_variance`), TCP advertised window dynamics (`swin_min`), fragment offset, header ratio, and retransmissions extracted via native Scapy DPI (`UniversalPCAPExtractor`) or proxy imputation.

Tier 3: Auth Velocity Fusion (Host Events)

Aggregates LANL Kerberos/NTLM authentication streams into continuous auth velocity, failed auth bursts, and fan-out degrees, tracking lateral movement ($T1078, T1021, T1550$) before credential harvesting completes.

Graph Topology Dynamics ($G_t = (V, E, X_t)$)

Interacting endpoints modeled as nodes $V$ (Ingress, Firewalls, DMZ, Active Directory, SCADA PLCs) and directed flows as edges $E$, tracking spatial lateral movement and spectral topology anomalies.
